# Roteiro de demonstração (5 minutos)

1. Mostrar a árvore de pastas (MVC).
2. Rodar o jogo no console: novo jogo, escolher perfil, tomar 2 ou 3 decisões.
3. Salvar no slot 1, sair e usar Continuar.
4. Abrir `saves/slot1.json` e mostrar o conteúdo.
5. Alterar uma linha do arquivo e carregar de novo: o jogo detecta a alteração.
6. Mudar uma configuração, reabrir o jogo e ver que foi mantida.
7. Rodar `mvn test`.
8. Abrir o menu JavaFX com `mvn javafx:run`.
